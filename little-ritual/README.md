# Little Ritual — cafea pentru o lume mică

Varianta în română a jocului [Little Ritual](https://little-ritual.openai.chatgpt.site/), rulată local din acest folder.

- Deschide `index.html` (sau [aici](/little-ritual/)) și apasă terminalul / Enter.
- Controale: WASD / săgeți pentru mers, Space pentru săritură, E pentru interacțiune, Q pentru întoarcere la cafenea.
- Progresul se salvează local în browser.
- Bonus: 12 stele colectabile ascunse prin lume (⭐ contor în colțul dreapta-sus).
